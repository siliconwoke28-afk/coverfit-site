KDP cover template

A KDP paperback cover is one wrap: back cover, spine, and front cover on a single sheet, plus bleed. The only variables are trim size, page count, and paper stock.

If your spine is wrong, the whole file is wrong. Start from the interior, not from the artwork.

Full-wrap formula

Width
2 × trim + spine + 0.25
Height
trim + 0.25
Bleed
0.125 per edge
Safe area
0.25 inside trim
Resolution
300 DPI

What the template includes

KDP's own template generator produces a PDF with three layers of guides. Understanding them is faster than downloading a template for every page count:

ZoneWhere it sitsWhat belongs there
Bleed0.125 in outside the trim on all four sidesBackground art that should run off the page
TrimThe final cut lineNothing critical, because cutting drifts
Safe area0.25 in inside the trimType, logos, and anything that must survive the knife
Barcode zoneLower-right of the back coverKeep it quiet; KDP prints the barcode there

How to build it without a template file

  1. Open the cover maker and set trim size and page count.
  2. Turn on guides to see bleed, trim, and the safe area.
  3. Place artwork so it crosses the bleed on every side.
  4. Keep all type inside the safe area, and leave the barcode corner empty.
  5. Export the PDF and run it through KDP's previewer before uploading the interior.

Template mistakes that get files rejected

  • Using a template from a different page count. A 20-page difference moves the spine by 0.05 in, which is enough to shift the front cover art.
  • Putting type in the bleed. It looks fine on screen and gets trimmed on paper.
  • Designing at 72 DPI. A 13 in wrap at 72 DPI is 936 px wide; KDP wants roughly 3,900 px.
  • Ignoring the barcode. A busy back cover with a barcode dropped on top reads as amateur.
