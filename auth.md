# CoverFit authentication and access

CoverFit is a static, browser-only cover tool. There are no accounts, API keys, OAuth scopes, or protected resources.

## Public access

- HTML pages: https://coverfit.app/
- Markdown twins: append `.md` to a page path, for example https://coverfit.app/kdp-cover-template.md
- AI summary: https://coverfit.app/llms.txt
- Full AI summary: https://coverfit.app/llms-full.txt
- Sitemap: https://coverfit.app/sitemap.xml

## Agent guidance

- All content is read-only.
- Cover images and text are processed locally in the browser and are never uploaded.
- There is no upload endpoint, no write API, no account system, and no payment flow.
- Use the public pages and Markdown twins as the source of truth.
- For corrections, email fit@coverfit.app.
